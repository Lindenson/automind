# ADR-006: Parallel research with Send

**Status**: Accepted · 2026-11-02

## Context

Research is per car × area and must be bounded, resumable and isolated from failures.

## Decision

`plan_research` creates `research_jobs` rows; `Send(research_job)` runs them in parallel; `collect_round` adds gap rounds bounded by depth (Quick 0, Standard 1, Deep 2).

## Consequences

One failing job never fails the turn. Jobs already DONE are not rerun after a restart (SC-013, tested).
