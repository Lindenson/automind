# ADR-017: Web search behind a provider port; Serper by default

**Status**: Accepted · 2026-11-02

## Context

Tavily cost about 3× all model calls and returned generic pages; the favourite spec sites were rarely found.

## Decision

Search goes through a cache-first `Searcher` port (`search_cache` in Postgres) over interchangeable providers
chosen in `config/search.yaml`: Serper (Google results) by default, SerpApi and Tavily as alternatives or fallback.
Providers return hits only; page text always comes from our own page store. Queries are built by code: favourite
sites per area and market first (`site:a OR site:b`), the open web next, at most 3 AI-proposed queries last (the
query planner never sees page text).

## Consequences

One-car comparison: search cost −93%. Repeat research within the cache lifetime is free. A provider change is a
config edit; the eval harness compares providers on the same benchmark.
