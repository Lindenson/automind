# ADR-020: One Docker Postgres for development, tests and deployment

**Status**: Accepted · 2026-11-02 (replaces the embedded development database of 002)

## Decision

The compose Postgres 16 service (`docker-compose.yml`) serves the deployed app, `scripts/dev.sh` (API on the
host) and the tests (`automind_test`); it is published on 127.0.0.1:5433 only. The embedded database was copied once
with `scripts/migrate-embedded.sh` (per-table count check) and stays as a fallback (`AUTOMIND_EMBEDDED_DB=1`).

## Consequences

Docker is required for development. The database password lives in `.env.docker` (git-ignored).
