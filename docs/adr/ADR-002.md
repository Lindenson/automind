# ADR-002: LangGraph as the orchestration engine

**Status**: Accepted · 2026-11-02

## Context

Turns need branching (ask, confirm, research, report), parallel research, interrupts for confirmation, and resumable state.

## Decision

The turn graph is a LangGraph `StateGraph` (`orchestration/graph.py`) with a typed runtime context (`TurnContext`) instead of module globals.

## Consequences

Interrupts, `Send` fan-out and checkpoints come built in. Graph nodes stay thin: business rules live in `domain/` and `application/`.
