# ADR-001: Modular monolith

**Status**: Accepted · 2026-11-02

## Context

One user, one machine, tens of chats. Distributed services would add deployment and consistency work with no benefit (constitution V, X).

## Decision

One deployable Python backend with layers `domain` (pure) → `application` → `orchestration` → `infrastructure` → `api`, enforced by import-linter (`backend/.importlinter`).

## Consequences

Simple deploys and debugging. Layer rules must be kept by the linter, not by convention. Legacy demo modules still reach the DB directly (listed as ignored imports until moved behind ports).
