# ADR-011: Graph checkpoints separate from domain persistence

**Status**: Accepted · 2026-11-02

## Context

Workflow state and domain data have different lifecycles.

## Decision

LangGraph `AsyncPostgresSaver` owns its tables; Alembic ignores them (`alembic/env.py`). Domain data (case versions, evidence, jobs, results) is in our own tables.

## Consequences

Checkpoint format changes never touch domain data; the case file is inspectable and editable.
