# ADR-008: Deterministic Python simulation engine

**Status**: Accepted · 2026-11-02

## Context

Race results must be reproducible and explainable (constitution III, IX).

## Decision

`domain/dragrace.py` (model `dragrace-0.1.0`): explicit Euler integration with labelled assumptions; results stored in `simulations` with the input hash.

## Consequences

Identical inputs give identical results (tested byte for byte). Not called realistic until calibrated against instrumented tests (SC-011; reference set pending).
