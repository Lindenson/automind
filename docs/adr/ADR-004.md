# ADR-004: PostgreSQL as the primary database

**Status**: Accepted · 2026-11-02

## Context

Evidence, catalog, case versions, turns, events, jobs and checkpoints need transactions and JSONB.

## Decision

PostgreSQL 16 (embedded via pgserver for local dev, Docker for deployment), schema under Alembic (`backend/alembic`).

## Consequences

One store for everything; advisory locks serialize per-variant recomputation (found by the research flow test).
