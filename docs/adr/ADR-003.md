# ADR-003: TypedDict for graph state, Pydantic for domain contracts

**Status**: Accepted · 2026-11-02

## Context

Graph state must be small and serializable; domain objects need validation (case deltas from the LLM, MCP payloads).

## Decision

`TurnState` is a `TypedDict` with compact references only; `CaseFile`, `CaseDelta`, `Interpretation` and identities are Pydantic models.

## Consequences

LLM output is validated at the boundary; the case file lives in the DB (versioned), not in graph state.
