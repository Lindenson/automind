# ADR-015: Criteria dictionary

**Status**: Accepted · 2026-11-02

## Context

Persona reports and "status"-type wishes need explainable, adjustable scoring (FR-025..FR-028).

## Decision

13 criteria in `config/criteria.yaml` with definitions, scales and persona default weights; scores are 0–100 indices computed in `domain/criteria.py` with named inputs; status = price class + segment + sourced brand positioning, age-adjusted.

## Consequences

Users see and change weights; unmapped wishes are reported as not assessable.
