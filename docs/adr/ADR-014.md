# ADR-014: Deterministic action policy

**Status**: Accepted · 2026-11-02

## Context

In the demo, an LLM decided what to do and asked nothing, re-researched the wrong car and repeated reports.

## Decision

`domain.policy.decide` chooses ASK / CONFIRM_VARIANTS / CONFIRM_COST / RESEARCH / ANSWER_FROM_CONTEXT / REPORT / ANSWER_GENERAL by fixed rules, with a case fingerprint against repeats; one unit test per rule.

## Consequences

The behaviour the user complained about is guaranteed by code, not by prompt luck.
