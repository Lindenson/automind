# ADR-016: Deferred: TanStack Query, React Router, LangSmith

**Status**: Accepted · 2026-11-02

## Context

The constitution's stack lists them; the MVP has one screen and gets server state over WebSocket.

## Decision

Not used in the MVP (constitution X): Zustand holds client state, the chat list is a drawer, tracing uses structlog plus the `llm_calls` / `search_calls` tables.

## Consequences

Revisit when the UI gets several routes or when per-step traces are needed.
