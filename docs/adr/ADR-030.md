# ADR-030: Identification ladder over sourced version lists; used cars costed as used

- **Status:** Accepted
- **Date:** 2026-11-04
- **Spec:** `specs/008-identification-ladder`

## Context

Identification guessed. It took whatever catalog row or resolver answer was at hand:
- the Octavia "2.0 diesel" became the one 115 CV row the catalog held;
- engines of other generations were offered;
- question kinds and counters interacted, so a state that no answer could leave was reachable (chat 9b5c0b0c).

A used car with no year was costed and scored as new.

## Decision

1. **The versions of each model generation** sold in Spain are a sourced, shared cache: table `model_versions`, port `VersionsStore`, 60-day TTL. A miss costs one search, ≤ 3 pages and the `versions` web reader. Code keeps a version only when its power is written in its excerpt and the excerpt occurs in its document.
2. **A pure ladder** (`domain/ladder.py`) narrows a car level by level:
   - generation, from the year or "on sale";
   - engine (fuel → family → power when there are more than 6);
   - gearbox;
   - drive.

   It offers only what exists under the levels above. What the user named that does not exist is said, with the options that do exist.
3. **No loops by construction.**
   - "Choose for me" (yes, go ahead, any) settles the level and every lower one by the base-version rule.
   - A level asked twice is settled by the same rule, with a note.
   - Ladder cars never reach PROPOSE or REMOVE_OR_CHOOSE.
   - A seeded property test drives 1,500 random scenarios.
4. **Corrections.** `reconcile` keeps the newer answer. It opens again only the levels below a change that the hub filled.
5. **Fallback.** Without a sourced list, the catalog and resolver path is used as before. The identity is said to be less certain, and no unsourced options are offered.
6. **Used cars** (`domain/used.py`):
   - a year not given after one ask is assumed from mileage or generation and labelled; age is never 0;
   - the purchase-price criterion uses the sourced used price for the year, else no data (never the new price);
   - depreciation starts from that price;
   - reliability adds a mileage effect;
   - the maker's warranty is shown as remaining or expired.

## Consequences

- A first chat about a model generation spends about one cent on the look-up. It is counted apart as `identify_search_calls`, not as research.
- Identification questions carry structured options. A tap sets the facts of one level, and labels are never parsed.
- Test fakes without a versions store keep the earlier identification, so the goldens are unchanged.
