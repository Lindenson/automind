# ADR-009: React + FastAPI over WebSocket (supersedes SSE)

**Status**: Accepted (amended) · 2026-11-02

## Context

`sec.md` planned SSE. The chat needs client → server messages during a turn (confirm, cancel) and replay after reconnect.

## Decision

One WebSocket per chat (`/ws/chat/{id}`, protocol v2) with a per-chat event `seq`; the server persists every event in `turn_events` and replays after `hello{last_seq}`. REST under `/api/v1`.

## Consequences

Reload or reconnect loses nothing; turns run as background tasks independent of the socket.
