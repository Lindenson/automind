# ADR-010: Evidence-first research

**Status**: Accepted · 2026-11-02

## Context

Answers must be research-grade and never invent data (constitution I, XI).

## Decision

Every value carries a verbatim excerpt checked against the document, units are normalized by code, generation-wide ranges are rejected, uncertain pages go to a validator role, and each area has a minimum; below it the report says "insufficient data".

## Consequences

Fewer values, but each one is traceable to a source.
