# ADR-013: Persistent chat thread and a versioned case file

**Status**: Accepted · 2026-11-02

## Context

The concept demo forgot the user between turns and repeated reports.

## Decision

One LangGraph thread per chat (`thread_id = chat_id`) and a `case_files` table with a new version per change (`changed_by` hub or user). The LLM proposes a typed `CaseDelta`; `domain.casefile.apply` applies it deterministically and logs the changes.

## Consequences

Memory is testable (golden dialogues assert case fields) and editable from the case panel.
