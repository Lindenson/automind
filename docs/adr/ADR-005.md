# ADR-005: One model gateway for OpenAI and Anthropic

**Status**: Accepted · 2026-11-02

## Context

Models per role must be swappable; usage must be counted for every call (constitution VII, FR-042).

## Decision

`infrastructure/llm_gateway.py` creates every chat model from `config/models.yaml` (`provider:model`) and attaches `UsageCallbackHandler`, which enforces per-turn limits and records `llm_calls` — including `create_agent` analyst steps and failed calls.

## Consequences

Switching providers is a config change. Prices in `config/prices.yaml` are placeholders until verified.
